## Ключевые находки и фиксы

### Навигация
- **GroupSetup без кнопки «назад»** (главная жалоба): событие `NavigateBack` было в компоненте, но в UI не выведено. Добавлена стрелка в `TopAppBar` (`groupSetup_button_back`). ✅ подтверждено скриншотом + тестом.
- **BoutConfirm**: не было `Scaffold` → контент под системными барами (edge-to-edge). Обёрнут в `Scaffold` + `TopAppBar` со стрелкой, нижняя «Cancel» сохранена.
- **BoutResult**: системный «назад» возвращал на уже сыгранный `BoutConfirm` (риск дубль-сохранения). Стек теперь атомарно тримится до `GroupDashboard`; `recordBoutResult` идемпотентен. Добавлены `systemBarsPadding`.
- **action_back**: стрелки «назад» озвучивали "Settings" (использовали `action_settings`). Добавлен ключ `action_back` (RU/EN) на 6 экранах.

### Тема / контраст («тёмное на тёмном»)
- Корень не в тулбаре (там `onSurface`/белый — корректно), а в **BoutScreen**: чёрная карточка `0xFF212121` исчезала на AMOLED `0xFF000000`. Введён доменный цвет `BlackCardSurface = 0xFF424242` — виден в обеих схемах. ✅ скриншот `23_card_dialog.png`.
- Жёлтая карточка: цвет текста перенесён на кнопку (`contentColor`), чтобы не сломаться на белом.
- Хардкод `Color.White/Gray` → токены `onBackground`/`onSurface`/`onSurfaceVariant`/`outline`.

### UX / валидация / i18n
- **SettingsScreen** был полностью на хардкод-русском → полная локализация (англоязычные видели русский). ✅ `02_settings.png`.
- Деструктив без подтверждения: **Reset**, **Skip section**, **Exclude fencer** — добавлены диалоги подтверждения.
- **GroupSetup**: валидация пустых/дублирующихся имён + Snackbar-ошибка; `singleLine` + IME-навигация по полям; убран no-op `Spacer(weight)` в скролле; обработка ошибки `createPool`.
- **Undo**: всегда отрисован (enabled + alpha) — тулбар больше не «прыгает».
- Тач-таргет индикатора карточки 32→48dp + `contentDescription`.
- **DE**: бесконечный спиннер при `bracket==null` → экран ошибки + «Повторить».
- `MoreVert`/«Name»/«BYE»/«TBD» — добавлены `contentDescription`/строки.
- BoutsList: пустой `onClick` давал ложный ripple на pending-карточках — убрано.
- BoutResult: магическая строка `winner` → `isLeftWinner`; согласованное выравнивание колонок.
